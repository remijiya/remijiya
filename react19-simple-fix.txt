SIMPLE FIX: npm install error in the app (React 19)
===================================================

Is it still React 19?
  YES. React stays at 19.3.1. We do NOT change React.
  We only update a few OLD packages that did not work with React 19.

What we change:
  @mui/material        5.10  ->  5.18   (same as the UI components library)
  @mui/icons-material  5.10  ->  5.18
  @reduxjs/toolkit     1.9   ->  2.5
  react-redux          8.0   ->  9.2
  @types/react-redux         ->  removed (not needed any more)
  react-ga                   ->  told to accept React 19

How to use this file:
  - Copy ONE command at a time.
  - Paste it in the VS Code Terminal and press Enter.
  - Wait until it finishes before the next one.
  - If you see red errors, STOP and send a photo of the terminal.

STEP 4. Update the old packages (one line at a time)
-----------------------------------------------------------
These commands edit package.json for you.
They print nothing when they work. That is normal.

npm pkg set "dependencies.@mui/material=~5.18.0"

npm pkg set "dependencies.@mui/icons-material=~5.18.0"

npm pkg set "dependencies.@reduxjs/toolkit=^2.5.0"

npm pkg set "dependencies.react-redux=^9.2.0"

npm pkg delete "devDependencies.@types/react-redux"

npm pkg set 'overrides.react-ga.react=$react'

## What
Keep React 19 and update the packages that blocked `npm install`:
- @mui/material, @mui/icons-material ~5.10 -> ~5.18.0 (same as pinch-ui-components)
- @reduxjs/toolkit ~1.9.1 -> ^2.5.0
- react-redux ~8.0.5 -> ^9.2.0
- removed @types/react-redux (react-redux 9 ships its own types)
- override so react-ga accepts React 19 (react-ga has no React 19 release)

## Why
`npm install` failed with ERESOLVE: these versions only allowed React 17/18.

## Testing
- npm install completes
- npx tsc --noEmit passes
- npm test passes
- Checked login, income page, dropdowns, text fields locally
