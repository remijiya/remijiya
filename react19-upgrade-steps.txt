Goal: make "npm install" work on React 19 in both repos.

Why it fails today: these packages only allow React 17/18:

  - @mui/x-date-pickers                  (v6)
  - @reduxjs/toolkit                     (1.9.7)
  - react-redux                          (8.0.7)
  - @testing-library/react               (v14, if used)

Versions that support React 19 (checked on the npm registry):
  @mui/material           ~5.16.14
  @mui/icons-material     ~5.16.14
  @mui/lab                5.0.0-alpha.177   (already OK)
  @mui/x-date-pickers     ^7.23.0
  @reduxjs/toolkit        ^2.5.0
  react-redux             ^9.2.0
  @testing-library/react  ^16.1.0  (+ @testing-library/dom ^10.4.0)

UPDATE (after checking "npm ls" in ui-components):
  i960-pinch-ui-components is ALREADY on React 19:
    react 19.3.1, react-dom 19.3.1, @mui/material 5.18.0,
    @mui/icons-material 5.18.0, @mui/lab 5.0.0-alpha.177,
    @mui/x-date-pickers 7.29.4, no Redux.
  So REPO 1 needs no version bumps. Only check its peerDependencies
  (REPO 1, step 2b below). The real fix is in REPO 2 (the app).
  In REPO 2 use the SAME versions as the library:
    @mui/material ~5.18.0, @mui/icons-material ~5.18.0,
    @mui/x-date-pickers ^7.29.4

Order: do REPO 1 (ui-components) first, publish it, then REPO 2 (app).

Rules:
  - Do NOT use --force or --legacy-peer-deps.
  - Do NOT use "git add ." (it would add .env.local).
  - Edit package.json by hand. Do not use "npm install <package>",
    because that re-checks the whole tree and fails again.
  - Node 24.19 is fine.

CODE FIXES (only where the search finds a match)
-------------------------------------------------------------

Redux Toolkit 1 -> 2
  OLD: extraReducers: { [fetchX.fulfilled]: (state, action) => { ... } }
  NEW: extraReducers: (builder) => {
         builder.addCase(fetchX.fulfilled, (state, action) => { ... });
       }

  OLD: configureStore({ reducer, middleware: [myMiddleware] })
  NEW: configureStore({ reducer, middleware: (getDefault) => getDefault().concat(myMiddleware) })

x-date-pickers 6 -> 7
  OLD: components={{ ... }}  componentsProps={{ ... }}
  NEW: slots={{ ... }}       slotProps={{ ... }}

React 18 -> 19
  OLD: ReactDOM.render(<App />, el)
  NEW: import {createRoot} from "react-dom/client";
       createRoot(el).render(<App />);

  OLD: MyComp.defaultProps = { size: "md" }     (function components)
  NEW: const MyComp = ({size = "md"}) => ...

  OLD: MyComp.propTypes = { ... }
  NEW: remove it (TypeScript types cover it)

  OLD: JSX.Element
  NEW: React.JSX.Element

  OLD: useRef<HTMLDivElement>()
  NEW: useRef<HTMLDivElement>(null)

  OLD: import {act} from "react-dom/test-utils"
  NEW: import {act} from "react"

  OLD: react-test-renderer
  NEW: @testing-library/react
